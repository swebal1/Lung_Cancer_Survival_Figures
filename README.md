# Figures for survival determinants of lung cancer

The visualizations below were published in the manuscript, "Survival Determinants and Socio-Demographic Disparities in Early Onset Lung Cancer in Young Adults: Insights From AI Modeling." Data were acquired from the SEER database. Visualizations were created in R.

### Stacked Bar Chart
Depicts the percentage of cases by lung cancer histology, stratified by age group. The code for this figure is in the file, "stacked_barplot_code.R"

### Incidence/Mortality Line Plot
Depicts the annual incidence and mortality (per 100,000) between 2010 and 2021, stratified by age group. The code for this figure is in the file, "incidence_mortality_plot.R"
